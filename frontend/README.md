# Frontend ITQ Conecta

Aplicación Angular 22 standalone con Angular Material. El dashboard consulta
`/api/health`; `npm start` reenvía las solicitudes `/api` a FastAPI en
`http://127.0.0.1:8000`.

Desde esta carpeta:

```powershell
npm install
npm start
```

La guía para iniciar todo el stack está en el [README de la raíz](../README.md).
